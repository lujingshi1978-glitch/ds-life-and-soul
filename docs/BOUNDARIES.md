# 权限、数据与安全边界

## 权限作用域

| 范围 | 说明 |
| --- | --- |
| 管理端 | 角色设置、账号连接、导入文件与授权配置，需要本机管理员身份 |
| 普通角色对话 | 受当前对象、通道、角色版本和实际工具门禁限制 |
| 平台读取 | 需要该平台已接入并启用；登录状态另行检查 |
| 平台互动 | 逐平台写权限与当前行动资格都要满足 |
| 独立工作 | 仅管理员明确委托，标准 DSH 会话并非 OS 沙箱 |
| 受限创造 | 专用 Windows LPAC 与验证过的运行时，缺失直接拒绝 |

通用浏览器交互开关仅对应管理端点击/输入，不能据此给普通智能体开放任意桌面操作。桌面微信与通用桌面控制仍未开放。

## 数据流

| 数据 | 去向 |
| --- | --- |
| 录音 | 本机临时 WAV 与本地 Whisper，识别结束清理临时音频 |
| 识别文字和对话上下文 | 本机 DSH，再交给使用者配置的模型提供方 |
| 默认朗读文本 | Edge TTS 服务；可关闭朗读或使用自行配置的其他引擎 |
| 网页地址与公开搜索词 | 使用者启用的网页/搜索服务 |
| 发送内容与动作参数 | 对应已连接的平台或 OneBot 网关 |
| 角色、记忆与来源 | 本机当前角色档案；不会自动成为公开演示数据 |

本机识别不会在缺模型时自动把录音转发给云识别。首次安装需要从官方源下载依赖与模型。对话、搜索、TTS 和平台访问仍有各自的网络目的地。

## 公开包与本机数据

源码包不包含实际 `config.json`、`state`、数据库、凭据、cookies、浏览器 profile、原 Git 历史、模型权重和虚拟环境。截图与演示 JSON 按素材清单分别标注合成数据、受控实验或已脱敏的真实问题材料，不公开私人原始记录。

发布前运行 `node scripts/check-public-package.mjs`。ZIP 必须使用同一个枚举器批准的源文件清单，不能直接递归压缩整个已运行目录。`.gitignore` 只能避免常规 Git 误提交，不能代替内容门禁。

## 未知与证据

未检索到记录不证明从未发生。转述、标题、评论、采样帧、完整内容和已执行动作是不同证据。系统应依据实际回执记录自己做过什么，失败或取消不能成为新的成功经历。

## 第三方与平台

SnowLuma 本体不随本仓库分发，启动器不自动部署或启动它。原创 OneBot11 客户端仅实现公开协议，不包含旧 SDK 实现。平台账号、登录和实际使用许可由使用者自行准备。

依赖各自适用原许可证。仓库 MIT 不替代 Qt、媒体库、模型或平台组件的许可。PyMuPDF 为显式可选依赖，其 AGPL/商业许可单独列明。参见 `licenses/` 与 `THIRD_PARTY_NOTICES.md`。

## 已知限制

语言模型的表达、联想、误记控制和提示注入防护都需要持续验收，不能宣传为所有情形下的保证。创建候选、列表中出现某动作、模型说想做某事，都不等于实际完成。

本轮未验证真实麦克风与扬声器的完整设备链，也未替使用者登录社交账号或发送真实消息。隔离测试与真实平台使用的范围要分别说明。
