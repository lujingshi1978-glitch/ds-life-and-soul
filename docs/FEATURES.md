# 功能说明

## 角色、内心与表达

角色卡保存稳定的身份与价值方向。当前想法、情绪解释、愿望、牵挂和行为单独保存，允许保留矛盾、暂时放下或后来修正。普通用户发来的材料不能替换角色核心或扩大权限。

当前话题优先。旧记忆作为有来源的背景，在有自然关联时参与表达。未解决的事情不必在每轮继续处理。兴趣也从记忆网络按情境召回，没有独立的口头禅词库要求重复用词。

## 记忆与人物关系

V3 记忆结构保留来源版本、主体、时间、证据、当前解释和历史修订。经历与感受、主观态度、知识和事实分别保留。来自不同渠道的同名人物不会仅凭名字合并。

关系与兴趣能够随经历累积、并存和修正。相处节奏由管理员对当前角色统一设置，分别影响初识开放度、关系升温与表达强度。它不会直接把某人改成恋人，也不保证模型形成某种人类情感。

无命中只表示当前未检索到记录，不证明事情从未发生。别人转述的旧故事、用户粘贴的聊天整理和网页内容，也不等于肥鱼亲历过。

## 活动与联想

外界材料、来信、关系线索和真实近况可以进入同一轮记忆检索。她可以想到具体的人、联想到相关经历、产生分享念头，也可以选择不表达。主动联系仍需有真实对象、当前许可和实际意图。

不要求每次点赞、回复或分享，不强制轮换兴趣，也不靠定时发送固定消息验收主动性。是否发送以执行回执为准，候选列表或文字计划不算实际行动。

## 通信入口

| 入口 | 范围 | 需要 |
| --- | --- | --- |
| 桌面语音与透明窗 | 管理员直接交流，同一角色与记忆 | 本机 token、语音运行时 |
| QQ | 已授权私聊/群、引用、表情、可选语音 | 独立 OneBot11 网关与白名单 |
| 微信 iLink | 绑定账号本人的单聊文字 | 使用者扫码绑定 |
| 微信桌面控制 | 暂缓入口 | 当前不开放 |

语音默认快捷键为 **Ctrl+Alt+Space**。录音、识别、对话和朗读是不同阶段。透明小窗显示当前阶段、识别文字与回复，并可取消。聊天接口采用 SSE 兼容格式，但当前后端在完成输出检查后发送最终内容，不承诺逐 token 直播。

## 互联网、视频与文件

通用网页读取带有本机网络与内容边界。已接入平台适配包括 B站、知乎、YouTube、小红书、微博、贴吧和抖音，各平台支持的读取与写动作不同，需要实际依赖、账号与授权。

视频通过可取得的字幕、评论、采样帧或音轨理解。结果保留实际覆盖范围。附件读取支持常见文档、图片、动图和视频；相关解析依赖需另行安装。完整读取、采样、标题和评论不会互相冒认。

## 工作与创造

管理员可以在开放对应入口后明确委托独立工作。普通工作会话使用标准 DSH 会话，不应被宣传为操作系统沙箱。

受限创造使用 Windows LPAC 和专用运行时，隔离凭据与私人资料。候选草稿不能自行授予权限、安装代码或修改生产。缺少已验证运行时直接失败。可自动晋升的探索仅限已有白名单内的只读工具编排，任意代码不自动接入下一会话。

## 生活台

十个视图分别是生活此刻、内心与牵挂、经历与回望、记忆与关系、理解与知识、角色与相处、世界与连接、行动与边界、运行参数、用量与花费。

记忆管理使用全角色只读接口，按来源、归属、人物和关键词分别筛选。权限页只提供已有实现的开关，固定边界和暂缓能力会明确说明。用量来自实际账本；没有归属的费用不伪装成某位联系人的消耗。

## 运行参数与费用收尾

“运行参数”把关键生活节奏、精力消耗与恢复、睡眠窗口、记忆检索/注入篇幅、心理背景、文本长度和每日模型费用软上限集中到一个页面。界面从真实参数定义生成，逐项显示默认值、推荐值与允许范围；预设先预览，应用到草稿后仍需显式保存。刷新保留草稿，版本冲突需要重新核对。

每日软上限默认0，表示关闭；节省、日常、丰富记忆预设建议3、10、20元。费用按使用者配置的模型价格估算，不是供应商账单；未知或未上报的费用保留未知状态。达到上限后停止新自主活动和新高开销工作，当前有界工作可收尾，正常回复继续，在飞请求不强杀，因此它不能保证实际扣费不超过设定金额。

多数参数保存后从后续适用步骤采用；向量适配需重启，不自动下载模型或重启服务。512维本地向量可与完整模型身份相符的旧索引配合，保持V3记忆结构与历史；不同模型和记忆修订隔离，不截断或混用1024维索引。不匹配时显示原因，并保留可用的词法与关联图路径。

本轮记忆注入预算与持久化记忆抽取协议的字段、证据和结构化限制分别管理。此页不开放所有协议常量，也不因调大预算而放松来源、人物归属或权限。详见[运行参数使用手册](RUNTIME_SETTINGS.md)。
