# 情境成长、记忆召回与经历来源

0.5.3 整合了已在本地实例验收的成长、记忆、关联和行动证据更新。全新安装仍建立新的角色数据，不导入开发者的记忆。核心价值与默认权限保持原有设计。

## 一件事如何留下影响

实际观察先保留来源、人物、时间和读取范围；模型可以形成当下心情、对某人的态度、某种兴趣或有范围的自我理解。它们分开保存，并通过证据引用连接。下一次对话根据当下情境召回相关内容，再由角色决定是否表达或行动。

正常成长与依据失效分别处理。新经历可以修正、扩展旧理解；某个历史节点未记录，不必使整棵来源树不可读。明确撤销、隔离或不允许读取的依据仍不能被缺口规则绕过。对特定人形成的倾向不能直接推广成面对所有人的固定性格。

## 召回与联想

记忆按当前问题、人物与场景排序，结合可配置的弹性字数预算打包；相关证据和具体细节优先于重复或仅主题相近的条目。需要时可以进一步补查。自主联想可以产生分享念头、关心或具体行动，但召回本身不要求继续旧话题，也不要求发送消息。

暂不分享会随时效、条件变化和新观察重新考虑；没有新依据时可以放下。忙碌、拒绝、授权与实际执行结果分别判断。没有记录不等于事情从未发生，聊天里的转述也不等于角色的亲历。

## 来源树和关联网络

在生活台「经历与选择」启用本机链路展示。可从行动、当前心情和稳定倾向进入，切换来源树和关联网络，点击节点核对正文与来源。

「显示设置」提供关键链路、详细关联、自定义，以及节点数量、展开层级、每处参考分支、版本沿革和间接关联开关。默认关键链路最多18个节点、3层、每处2条参考分支。它仅调整本机显示；不删除记忆，不改变检索或行动。反证和未知依据优先保留。

界面只展示已保存的事件关系、可见解释和回执，不保存或展示模型的隐藏推理。关联连线也不表示已经证明心理因果。知识来源按标题、链接、正文与核查状态展示，避免直接显示原始JSON。

## 自身行动必须有依据

「想看」「准备分享」「已经打开」「发送成功」分别处理。历史动作描述要核对读取或执行记录；未确认的动作不补写成做过。发送失败、取消和未知回执保持原状态；没有依据时可以表达当前关心，而不用虚构先前行为。

## 验证范围

仓库提供临时数据库、合成人物和本机协议夹具测试：

```powershell
npm --prefix packages/feiyu run test:memory-growth
npm --prefix packages/feiyu run test:agency
```

历史真实模型隔离实验观察到「暂缓→暂缓→新信息后主动聊天」的轨迹；发送端为本机受控接收器，不是向真实QQ好友外发。情境成长与跨窗口召回实验使用模拟人物和压缩时间，不能证明长期真人陪伴效果。小型检索对照有改善，但不构成通用数据集领先结论。

创造实验只证明受限工具候选能够产出、测试和修补。部分候选未通过晋升检查，不代表任意代码都可自动接入。开发中的私有运行时一键安装器不属于此源码版本。
