# 持续关注与行动历史

一次行动的临时动机与长期牵挂使用不同的生命周期。宿主为行动保存的 motive 标记为 action 生命周期，供行动校验和历史追溯使用，不再进入长期关注、下一轮内心材料和生活台的牵挂列表。决定休息、发呆或暂不行动仍然允许，不会因此被强制安排别的活动。

已有数据通过 `v3_ongoing_lifecycle` 派生索引整理：只有能追溯到行动提案原始动机、且内容仍对应原行动的条目才归入行动历史。后来被明确改写为不同内容的条目保留。原对象、版本、证据、动作和回执均不删除、不重写。

独立关注条目只有在人物与来源情境一致、正文和语义字段完全一致时才合并关注入口。不同人物、相反表达、情感强度和不同承诺事件不自动合并；来源不足也不自动合并。新的相同关注承接原 ID，真实变化仍应由模型引用旧 ID 更新。语义相近但无法证明相同的条目保留，不能靠关键词批量删记忆。

页面不再将相同的标题与正文重复显示。行动历史仍可追溯，退出持续关注不表示事情已经解决、承诺已经兑现或未知回执已经确认。

隔离测试覆盖 80 次连续休息/暂不行动、跨人物、相反感受、不同承诺、不同强度及旧数据整理。真实库副本整理前后对原有 125 张表逐行哈希比对一致；派生索引之外没有改动。该副本测试不代表真实模型多日运行已经验证。
