# 网站接入与语音字幕

在「互联网与应用」中，每个平台都有独立的检查、登录、读取和互动入口。页面分别显示读取组件、互动组件、登录和权限状态；安装依赖不会自动允许评论、点赞或自主活动。

## 接入网站

1. 点击「安装读取组件」。首次需要网络和可用的 npm，安装锁定的 OpenCLI 2.0.2 与 Playwright MCP 0.0.83。重复安装保留平台配置。
2. 按卡片里的官方说明，在打开生活台的浏览器中安装 OpenCLI Browser Bridge 扩展。安装程序不会替你安装浏览器扩展或导入个人浏览器资料。
3. 保留一个浏览器打开生活台，点击「打开登录」。平台登录在该浏览器的新标签页中完成。
4. 回到生活台点击「完成登录」「检查连接」。Cookie 存在仅是登录线索，实际读取仍可能需要验证或重新登录。
5. 勾选「启用读取」并保存，再选择读取、评论、搜索或推荐。读取结果会显示实际来源与范围；文字结果不能证明看过完整视频。

哔哩哔哩使用原生插件：先停止本包，在安装向导中选择 B站/动图组件并重启，再从执行服务完成扫码。对已安装的受管 profile，重新选择该组件会真正添加插件；不会修改自行编辑过的 profile。

小红书的部分原生互动和微博的原生发布组件并未随源码包分发。「读取组件已安装」不代表所有互动均已可用。缺少组件会明确提示，不能通过勾选权限补齐。账号、平台风控、网络可达性和网站改版仍会影响结果。

人工互动先「预览互动」，核对平台、目标与文字后再「确认提交」。修改内容后必须重新预览。结果未知时去原页面核对，不自动重发；同一未核实操作跨日、重启后仍阻止重复提交。旧记录缺少子评论身份时会保守阻止相同目标、动作与文字的重复。肥鱼的自主行为仍使用原有宿主权限与回执机制；人工按钮不强制肥鱼分享、浏览或更换兴趣。

## 快捷语音与字幕

启动后语音入口驻留托盘。Ctrl+Alt+空格开始说话，再按一次结束录音；不会弹出大聊天窗。录音、识别出的文字和回复显示为不抢焦点的小字幕。托盘菜单仍可打开备用文字窗。

通过托盘「设置」可以调整字幕开关、不透明度（20%–100%）、字号（12–40）、宽度（260–1800 像素）、横纵坐标、停留时间（0 为常驻）和鼠标穿透。默认底部居中、18 号、640 像素宽、86% 不透明，回复结束后保留 10 秒。关闭鼠标穿透后可拖动字幕，松开即保存；调整完建议恢复穿透。

客户端设置不保存令牌。重复安装保留字幕偏好和自定义快捷键，只更新本包的网关与凭据文件位置。字幕设置兼容旧配置。完整文字可在备用文字窗查看；字幕只显示最近数行，以减少遮挡。

## 解包与诊断

使用 Node 24，先完整解压后运行安装向导。核心依赖缺失可运行 `scripts/修复核心依赖.cmd`。不要把不同版本的 node_modules 或开发机路径拷入发行包。

`npm run doctor` 区分「已配置」和「健康」。停止状态会显示 degraded；诊断同时核验进程身份和真实就绪响应，不把无关端口监听当作健康。语音检查会实际导入依赖并核对本地模型清单，不只检查 Python 文件是否存在。平台账号在线和真实网站动作仍须单独验证。

私人 state、配置文件、浏览器资料的权限验证失败时，启动会中止。不要把私人运行目录设成指向其他用户资料的链接。费用软上限大于 0 时，费用未知会暂缓新自主活动，已接收的普通来信回复继续；设为 0 表示不启用费用软上限。
