# QQ接入：从登录到连接

适用版本：0.4.1起。肥鱼和DSH由整合包安装；QQ登录端需要单独安装、启动并登录。OneBot11是双方通信的接口协议，这里没有单独的“OneBot许可证”申请步骤。具体网关的安装和使用按其项目说明进行。

## 准备QQ网关

可以使用支持OneBot11的网关。NapCat的官方入口为 [NapCatQQ](https://github.com/NapNeko/NapCatQQ)，网络配置见[官方配置指南](https://github.com/NapNeko/NapCatDocs/blob/main/src/config/basic.md)。已有SnowLuma的用户也可以继续使用其OneBot接口。

1. 按所用网关的官方步骤安装，启动并登录用于肥鱼的QQ账号。
2. 在网关中为这个账号开启下面两个服务。

| 网关设置 | 填写内容 |
| --- | --- |
| 正向WebSocket服务端（WS Server） | 监听 `127.0.0.1`，端口 `3001`，同时提供API和事件 |
| HTTP服务端（HTTP Server） | 监听 `127.0.0.1`，端口 `3000` |
| 连接令牌 / access token | 自己设置一段非空、无空格的随机令牌，两个服务使用相同值 |
| 消息上报格式（若可选） | `array`，即消息段数组 |
| 自身消息上报（若可选） | 关闭，避免把自身消息重新当作输入 |

端口被占用时，可以另选空闲端口，并在肥鱼向导中填相应地址。不要选反向WebSocket客户端，也不要把网关的管理网页端口当作接口端口。网关与肥鱼需在同一台机器；当前向导只接受上述本机根地址（也支持IPv6回环地址），不接受公网、带令牌查询串或 `/event` 等分离端点。

## 使用接入向导

首次运行 `启动肥鱼.cmd` 时，可以选择“安装完成后配置QQ接入”。没有准备好网关时选否，桌面聊天仍可使用，之后再连接。

已有安装：先双击根目录 `stop.cmd` 停止这份肥鱼，再双击 `scripts/配置QQ.cmd`。停止肥鱼不会关闭自行运行的QQ网关。也可在根目录终端运行：

```powershell
node scripts/deploy.mjs qq
```

按提示填写：

1. 网关名称用于本次确认，不会自动选择、下载或启动软件。
2. WS地址，例如 `ws://127.0.0.1:3001`。
3. HTTP地址，例如 `http://127.0.0.1:3000`。
4. 在网关中设置的连接令牌。输入不回显；留空沿用已有令牌，新安装没有令牌时不能跳过。
5. 管理员QQ。这是操作肥鱼的人的账号，和网关中登录的肥鱼账号区分。桌面模式的内部占位值 `1` 不能用于QQ接入。
6. 允许回复的其他QQ和群号，逗号分隔。留空沿用已有列表；输入 `-` 清空该列表。管理员会加入私聊允许范围。
7. 核对后输入 `yes` 才执行检查和保存，其余输入取消。

向导通过HTTP和正向WS分别查询 `get_login_info` 与 `get_status`，确认令牌可用、账号在线、两条连接属于同一个账号。它不获取联系人列表、不发送消息、不执行点赞或评论；收到的普通事件不保存。

通过后才保存。原配置备份到本机 `.local/qq-setup-backups/`，其中可能含有凭据，不能提交到仓库。参数保存到已有 `packages/feiyu/config.json`，不会写入公开示例或安装计划。重新运行 `启动肥鱼.cmd` 生效。

失败时不会保存候选配置。若肥鱼仍在运行、配置被其他窗口修改或所选对象位于黑名单中，会拒绝覆盖并提示处理。已有核心、记忆、黑名单、主动联系及其他网站行动开关保持原值；接通QQ不会自动开放所有好友或开启主动聊天。

## 检查与排错

已配置后，可随时进行只读检查，运行中的肥鱼无需停止：

```powershell
node scripts/deploy.mjs qq-check
```

`node scripts/deploy.mjs doctor` 也包含同样的QQ检查。未启用QQ时不连接网关。

| 提示 | 检查方法 |
| --- | --- |
| WS无法连接 | 确认正向WS服务端已启用，端口正确，同时支持API与事件 |
| HTTP不可用 | 确认开启的是HTTP服务端，地址没有填WS或管理页面端口 |
| 令牌不匹配 | 核对对应服务端令牌；WebUI管理令牌和OneBot连接令牌可能不同 |
| 账号未在线 | 在网关中完成QQ登录，再重试 |
| 两条连接属于不同账号 | 将HTTP和WS服务都配置到同一个QQ账号 |
| API拒绝或格式不符 | 核对是否OneBot11实现，查询接口是否兼容；不要靠反复发消息测试 |
| 需先停止肥鱼 | 使用当前目录的 `stop.cmd`，不要关闭其他安装的肥鱼或QQ服务 |
| 保存成功但不回复 | 重启肥鱼，核对允许范围及黑名单，再查看生活台连接状态与本机日志 |

本向导已用本机HTTP/WS协议夹具验证连接、鉴权、在线状态、账号一致性和保存边界。未用NapCat或其他新增网关完成真实QQ登录和社交发送验收，因此不承诺其所有扩展接口都与原运行环境一致。语音、表情、合并转发或动态等扩展能力需按网关实际支持情况验证。
