# 排错

## 双击后立即退出

确认安装的是含 npm 的 Node.js 24 LTS。在终端运行 `node scripts/deploy.mjs doctor`。Windows 建议解压到 `D:\Feiyu` 一类短路径，不要在 ZIP 内运行。

## 端口被占用

启动器不接管未知进程，也不会为了部署肥鱼停止别的 DSH/QQ。先关闭冲突的自有实例，或在首次安装配置中改变三个端口。不要用端口查到一个 PID 就直接强杀。

## 数据库无法打开

先检查路径长度、目录可写和磁盘空间。深层目录在 Windows SQLite 中可能触发路径限制。将未运行过的干净包解压到短路径；已有数据请先备份，不要直接删除数据库或 `state`。

## DSH 能开但肥鱼没有模型回复

查看本机 DSH 界面是否已配置模型凭据，模型名称是否实际存在。默认新 profile 不复制旧 DSH 的凭据。生活台和插件健康正常不代表云模型调用已经成功。

## Ctrl+Alt+空格没有响应

确认语音客户端正在运行，快捷键没有被别的软件占用。先用窗口按钮检查状态。检查 `.local/hotkey-config.json` 的快捷键、网关地址及凭据文件路径。不要把管理员 token 填进 pet 凭据字段。

如果缺少 Qt 或音频组件，重新运行语音安装。不能录音时也可以先用透明小窗文字输入，原角色与记忆仍共用。

## 语音依赖下载很慢

若提示“未找到Python 3.11”，先确认本机已安装该版本。0.4.2起支持从Python Launcher列表识别uv/Astral登记项，避免“列表里有3.11，但 `py -3.11` 找不到”的兼容问题。未登记且不在PATH的安装，可用 `FEIYU_PYTHON` 指定其解释器绝对路径；不是把当前默认的其他Python版本改名成3.11。

首次需要下载 Qt、音频和识别依赖。发行验证中曾遇官方 Qt wheel CDN 持续吞吐不足，安装未能在预算内完成。安装器会记录失败，不把它标成就绪。

使用稳定网络重试，缓存只保留在本机。不要从来历不明的安装器、打包群文件或镜像复制可执行文件。已安装的本机依赖可以在核对版本与来源后复用；复用和从零下载是不同验收范围。

## 本地识别模型不完整

识别器要求固定来源模型的必需文件和 manifest。缺文件、链接或 hash 不匹配会明确失败，不隐式下载，也不回退发送录音到云端。重新完成本地模型安装，不要从另一个人的角色档案复制未知模型缓存。

## 有文字但没有朗读

确认客户端启用播放、后端 TTS 已配置，音频输出设备可用。默认 Edge TTS 需要网络。TTS 失败不会删除已经收到的文字回复。

## QQ 未连接

全新安装的QQ默认关闭。网关登录后，使用 `scripts/配置QQ.cmd` 配置连接，或运行 `node scripts/deploy.mjs qq-check` 只读检查。HTTP和正向WS必须属于同一个已在线账号，不能把管理页面或反向WS地址填进去；连接令牌也可能与WebUI管理令牌不同。完整步骤见 [QQ接入指南](QQ_SETUP.md)。

## 网页或平台能力不可用

检查 Edge、Playwright MCP、可选插件依赖、账号登录和平台授权。支持某个平台不代表当前账号可访问全部内容；验证、私密权限、平台变化和链接失效需要如实处理。资料读取失败不能补造内容。

## 创建工具时被拒绝

确认管理员明确委托、创造入口已开放、专用 LPAC 运行时就绪。不要通过改成普通工作会话或开放宿主 Shell 绕过隔离拒绝。当前源码包不包含开发机器上的运行时二进制或私人工作区。

## 停止后仍有进程

停止器只处理已记录且再次核对身份的进程。身份漂移时会保留记录并报告，而不是强制杀掉未知进程。先查看 `.local/processes.json` 和本机日志；提交 issue 前删除 token、完整命令、个人路径和聊天内容。
