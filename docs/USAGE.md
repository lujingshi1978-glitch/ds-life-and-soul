# 使用手册

## 直接与肥鱼交流

启动后按 **Ctrl + Alt + 空格** 开始语音录音，再按一次结束。原有录音体验保留：短暂停顿可自动结束，无声音会结束等待，单段录音最多约59秒。录音尚未结束时可取消，取消的音频不会继续提交。

语音快捷键只显示录音状态和小字幕，不弹出聊天大窗。托盘「设置」可调整字幕的透明度、尺寸、位置、停留时间和鼠标穿透；从托盘打开备用文字窗后仍可打字、取消或查看完整回复。关闭窗口会隐藏它；结束客户端请使用托盘退出或 Ctrl+Q。退出不清空肥鱼的本地记忆。

语音路径为本机录音、本地识别、同一肥鱼的对话、按需朗读。识别出的文字会作为对话输入交给 DSH。朗读可在客户端设置中关闭；关闭朗读后文字回复仍保留。

## 认识当前状态

生活台首页展示实际记录的行为和想法。记录时间与页面同步时间分别显示。没有行为记录时不补造“刚才在做什么”。持续的牵挂不是必须立即完成的任务。

## 查找记忆与关系

进入“记忆与关系”，选择全部记忆、经历与感受、人物关系与态度或来源记录。来源、归属与人物是独立的过滤条件。点击“查找记忆”应用条件，再按需加载下一页。

同名的 QQ 与微信身份分别展示。关系卡片是肥鱼当前的主观理解，展开来源依据可看证据引用。来源视图展示元数据，不能据此声称已读完整原文。

## 设置角色与相处

在“角色与相处”中查看核心、角色卡、表达偏好和相处节奏。修改前先载入，修改后显式保存。换页保留草稿；角色或版本发生变化时会拒绝用旧页面覆盖新设定。

初识开放度、升温速度与表达强度是整个角色的偏好。共同经历和对方边界继续有效。

## 调整节奏、篇幅与每日花费

打开生活台“运行参数”。四组分别管理生活节奏与精力、记忆检索与注入、文本与持续内心、每日花费与收尾；它们影响当前本机的所有角色。每项都显示实际默认值、推荐值与允许范围。

可以先选择推荐预设，点“预览推荐”核对差异，再“应用到草稿”。这些步骤都不保存；点击“保存参数”才提交实际改过的字段。换页和刷新状态保留草稿，同一标签页重新载入也会尝试恢复；“取消草稿”恢复最近读取的服务器值。参数版本变化时先核对新版本，旧页面不能直接覆盖新设置。

初次建议从“日常推荐”开始，再观察费用与实际表现。节省、日常、丰富记忆预设的每日软上限分别为3、10、20元。**原始默认值为0，即不启用上限**，不会因页面显示“推荐10元”就自动开启。账本按配置价格估算已知费用，未知费用单独标明；这些金额不是准确账单。达到上限后不再开启新的自主活动或高开销工作，已开始的有界工作收尾，正常来信仍回复，不强杀正在返回的请求。

节奏、精力和文本设置从后续适用步骤采用；缩小篇幅不会直接删除历史记录。向量适配需重启后采用，不会自动下载模型或重启服务。512维适配保留V3记忆，旧索引按完整模型身份与记忆版本隔离，不把1024维截成512维，也不混用不同模型的索引。

这些篇幅是本轮选择、阅读和注入的预算，不能一并放大持久化记忆抽取协议的字段或证据上限。角色核心、来源、人物归属和权限继续保留。完整字段表和生效说明见[运行参数使用手册](RUNTIME_SETTINGS.md)。

## 开放行动

“行动与边界”把自主活动、网站、通信、工作与创造放在一起。逐项核对作用范围，再显式保存。平台登录状态与权限开关分别显示。

全新安装默认不自动联系好友、不自动操作网站。QQ请先按[接入指南](QQ_SETUP.md)登录网关并运行 `scripts/配置QQ.cmd`，检查地址、令牌、管理员与聊天范围，再在生活台核对对象和黑名单。微信文字连接在“世界与连接”中扫码管理。

网站卡片可以安装组件、检查连接、打开登录、读取内容与预览人工互动，步骤见[网站接入与字幕说明](PLATFORM_CONNECTIONS.md)。安装适配器、浏览器扩展、平台登录和行动权限各有自己的状态。

## 常用命令

```powershell
node scripts/deploy.mjs launch
node scripts/deploy.mjs doctor
node scripts/deploy.mjs stop
```

生活台端口默认3110，DSH模型配置界面默认3081。本地访问令牌在运行时生成，不要把带令牌的地址截图、提交到 issue 或发给别人。

## 演示素材

`examples/cross-source-demo.json` 和 `docs/screenshots/` 是合成素材。它们用于说明来源、人物与联想的关系，没有进入生产记忆索引。测试 QA 和演示文本不应自动成为角色的真实经历。
