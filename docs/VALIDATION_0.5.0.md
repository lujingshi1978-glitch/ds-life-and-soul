## 持续使用模拟

使用真实认知宿主和 SQLite，模拟 3 人 500 条消息，以及 2400 次历史写入；检查重复去重、乱序排序、数据库重开、北京日期切换、睡眠、费用正常/未知/达到/新日恢复、角色切换和旧回执隔离。时间推进是测试时钟，不代表连续运行了数天。

独立验收执行 150 次真实本地 API 请求，约 2.69 秒；短时工作集约从 115.6 MB 到 121.3 MB，线程数保持 13、句柄从 346 到 347。这个观察不能证明长期没有资源泄漏。测试结束关闭全部自有服务和 6 个测试端口，保留合成证据。

## 未测与保留项

- 没有启用真实社交账户、浏览器扩展、对外评论或消息；按钮夹具通过不能证明各平台账号全链路可用。
- 没有打开真实麦克风、扬声器或注册系统热键，也没有完成多屏和系统睡眠实测。
- 没有调用真实对话模型或重做 GB 级下载断点恢复；本轮部分官方依赖从已核验缓存复用。
- 没有改变角色核心、人格、真实记忆或正在运行的用户服务。
- 统一数据保留期和彻底删除流程尚需单独设计；本版不会自动清除用户记忆。

核心、部署、语音安装、客户端和隐私检查脚本随源码提供，可在自身隔离环境复跑。私人验收日志、账号、凭据与真实聊天不随公开包分发。
