# 0.5.3 公开源码验证

日期：2026-10-30。源码整合本地已验证的 r2 至 r7 功能；发布过程不修改或重启运行实例。

| 检查 | 本轮结果 |
| --- | --- |
| 部署、配置、权限与公开包测试 | 65 通过 |
| 核心、记忆、表达与传输回归 | 233 通过，1 项因没有安装隔离 DSH 宿主而跳过 |
| 情境成长、来源有效性、关联与弹性召回 | 299 通过 |
| 自主调度恢复、输入打包、选择与自身行动依据 | 73 通过 |
| 公开包门禁测试 | 16 通过，包含在部署测试组内 |

各组可能验证相同机制，不把数字相加作为独立实验数量。测试使用临时数据库、合成人物和本机协议夹具；本轮没有付费模型调用，没有真实社交外发，也没有重新执行麦克风、全局快捷键或干净 Windows 虚拟机测试。CI 仍保留已有桌面语音和字幕检查。

更新三处过时测试契约：输入过大使用专用错误码及实际输入上限；空闲调度的夹具初始化使用当前尝试状态。仍验证输入过大时不调用模型、输出保持完整，以及自主浮现不成为指定行动。临时数据库与报告写入不纳入发行的测试目录。

公开门禁核对文件白名单、凭据模式、调用方私有标识、Office/PDF文本、第三方许可、锁文件摘要、原生组件来源和 Git 暂存内容。公开包不包含开发者数据库、凭据、账号配置、浏览器资料、模型权重、安装缓存或一键部署签名私钥。

历史真实模型隔离实验与当前源码测试分别解读：暂缓后重新选择的观察不能保证每轮都主动分享；有情境的成长不能证明所有关系会自然发展；小型召回对照不能代替独立通用数据集评估。详见 [情境成长与召回](GROWTH_AND_RECALL.md)。

0.5.3 沿用源码部署流程。运行时自包含安装器仍独立开发和验收，未作为已经完成的功能发布。
