## 安装与使用

1. 下载完整 ZIP，解压到普通文件夹。不要只拖出其中的 exe，也不要直接在压缩包内运行。
2. 双击 `肥鱼.exe`。默认服务为 DeepSeek；填写 API Key 后点击“安装并打开”。兼容服务还需填写地址和模型名称。
3. 从生活台登录需要的平台账号。QQ 为可选连接，需自行准备已获使用许可的 OneBot11 网关。
4. 下次从生成的“肥鱼（一键版）”入口打开，不必重复安装环境或重做初始化。已有不同目标的入口会保留，发生同名冲突时使用实例专属名称。

包内携带 Node 24.19.0、CPython 3.11.15、DSH 0.2.0-rc.2、本地 Whisper small 模型及相关依赖；不修改系统 PATH。每个受管理实例使用独立端口、DSH 档案和私有运行目录。

默认实例位置为 `%LOCALAPPDATA%\Feiyu-Life`。首次建议至少留 8GB 空闲，升级还需容纳现有数据与快照。API 密钥存入实例的本机私有档案，不写进快捷方式或进程参数。

## 快捷语音与字幕

快捷键为 **Ctrl+Alt+空格**：开始录音，再按结束；停顿也可自动结束。识别和回复以透明字幕呈现，不因此弹出主聊天窗。字幕透明度、字体、大小与位置可从语音设置调整。设备、麦克风授权和声卡效果须在实际电脑确认；快捷键被占用时可改键。

## 升级、回退与数据

从现有一键版入口选择“升级”，选新包解压目录。部署器先校验签名和全部文件，再停止自己的服务，保留升级前快照并迁移角色、记忆、聊天、配置及本机凭据。新版本初始化或健康检查失败时会恢复原版本；目录切换中断也有事务恢复。

“回退上一版”恢复升级前状态，并另存当前版本及数据。不要手动删实例中的 `backups` 或未完成事务记录；需要完整移除前先备份实例目录。

这些操作针对**本部署器管理的实例**。普通启动不会自动接管源码部署或旧散装目录，也不会自动导入开发者记忆。当前数据格式修订为 1；不同格式会拒绝升级，等待专门迁移，不能把本次测试当成跨格式迁移证明。
