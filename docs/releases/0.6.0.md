## Windows 一键部署版

下载 **Feiyu-Windows-0.6.0.zip**，完整解压后双击 **肥鱼.exe**，填写 API，再登录需要使用的平台账号。已携带 Node 24.19.0、Python 3.11.15、DSH 0.2.0-rc.2、本地语音识别模型及依赖，无需另装这些编程环境。

### 这次提供什么

- 独立实例、自动选择本地端口、私有 DSH 档案，不修改系统 PATH，也不自动接管旧开发目录。
- 同数据格式升级保留记忆网络、聊天、角色、配置与本机凭据；失败自动恢复，手动回退保留当前快照；目录切换中断后可恢复。
- Ctrl+Alt+空格快捷语音与透明字幕，可调透明度、大小和位置。
- 修复子进程归属中的 PID 复用问题、模型推理参数兼容、中文 ZIP 文件名、原生入口输入管道以及英文 Windows 的中文快捷方式；已有入口不会被覆盖。

### 实际验收

干净 Windows 11 x64、普通用户、没有预装 Node/Python/DSH：14 个实际验收阶段通过，覆盖安装、重开、真实 SQLite 记忆、原生 DSH/API 链路、随包 Whisper 实际识音、Qt 字幕、快捷键注册、升级、自动恢复、手动回退、中断恢复和进程清理。

原生入口另外完成连续管理器往返；4 个已有测试快捷方式未改，2 个中文自定义实例入口的参数正确。专项测试为进程归属 7 项、模型兼容 3 项、语音客户端 21 项；公开回归 26 通过，13 项依赖私人历史库的场景明确跳过。

API 链路使用本地兼容模型，语音使用合成音频；没有用真实 QQ 外发或付费模型调用凑结果。完整 14 阶段验收后，仅追加原生界面及其源码修复，部署、记忆、回退组件的哈希未变，并对最终包重新签名和逐文件校验。

### 范围与注意

- 已验 Windows 11 x64；Windows 10、ARM 未在本次干净环境中验收。
- 实体麦克风、声卡播放和真实账号登录需使用者实际体验。默认在线朗读和云模型需要网络。
- QQ 网关需自行配置已获许可的 OneBot11 服务。本包不携带该网关、PyMuPDF、独立向量模型或受限创造执行环境。
- 升级/回退针对本部署器管理的实例；不兼容的数据格式会拒绝升级，不代表跨数据库格式迁移已通过。
- 下载上方 Windows ZIP。GitHub 自动生成的 **Source code** 是源码，未包含这些大运行时。
- 安装包中 `payload/app` 保留该冻结候选的完整应用源码，`source` 保留原生入口源码；精确文件对应关系见 `release.json`。仓库源码版继续维护，不能用文件名或版本号代替逐文件对应。
