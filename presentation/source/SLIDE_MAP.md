# 介绍结构

共14页，面向第一次接触项目的开发者与 GitHub 读者。

1. 肥鱼：跨来源的持续生活智能体
2. 项目哲学：稳定核心、来源经历与主观选择
3. 能力范围：完整模块及各自运行条件
4. 一轮跨来源体验：明确标注的合成情境
5. 记忆、经历与来源：资料、感受、整理和回忆
6. 关系与兴趣：人物依据、复杂态度与语境召回
7. 主动活动：活动选择和真实回执
8. 行动与边界：读取、通信、工作和受限创造
9. 生活台：合成数据的记忆页面
10. DSH 插件与对话入口：快捷键语音与透明弹幕小窗
11. 安装与第一次使用：首次配置与后续统一入口
12. 架构：通道、角色循环、DSH工具与本地档案
13. 验证范围与局限：证据与实际使用边界
14. 开源与贡献：公开范围与可复现的贡献方向

第10、11、13页从 `release-status.json` 读取最终交付状态。它们必须与安装文档和实际验收一致。

原生可编辑对象包括：正文、表格（第3、6、8页）和流程/架构图（第4、5、7、12页）。图片仅用于明确的合成产品截图与抽象装饰背景。
